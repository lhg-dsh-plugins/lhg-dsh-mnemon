# 文档导航与索引

[English](./README.md)

对文档的审查发现：有些页面和记录没有任何索引能到达，有些链接已过时或在 GitHub 之外会失效，有些索引只列出了所在目录的一部分。本改动在不移动内容的前提下修正这些问题。2026-10-17 基于 [#386](https://github.com/omdsh-dev/dsh-mnemon/pull/386)（`51b1dd8e`）检查。

| 位置 | 之前 | 之后 |
|---|---|---|
| [发布历史](../../zh-CN/releases/README.md)（两种语言） | 只有 v0.5.3 至 v0.5.30，v0.4、v0.3、v0.2 标题下为空 | 全部 63 份说明，从 v0.2.0 到 v0.5.30，标题取自各自的说明 |
| [本索引](../README.md) | 缺 21 份记录，其中三份没有任何链接；19 行只有英文 | 每份记录都按时间列在相邻记录旁，每行都有中英文；并注明记录中的命令指向其测试版本时的文件 |
| [`docs/plans`](../../plans/README.md) | 六份计划没有任何链接 | 新增列出各计划状态的索引，并从开发指南链接 |
| [`docs/README.md`](../../README.md) | 让已有用户去看 v0.5.17 发布说明 | 改为指向兼容性与升级以及发布历史 |
| 两种语言的 README | 贡献指南与安全策略链接固定在 2026-09-06 的一个提交 | 与 README 其他链接一样使用 `blob/main` |
| SECURITY.md | 指向兼容性页面的相对链接，在 npm 包页面上会失效 | 改为绝对链接 |
| [配置参考](../../zh-CN/reference/configuration.md) | 英文页缺少“运行中的回合与委派任务保留哪个运行图”这一段 | 两种语言都有 |

## 检查

- `pnpm run verify:docs`：4,237 个本地链接与 217 个锚点都能解析，每个页面都有两种语言。
- 用脚本核对了发布索引的每个条目与对应说明的标题（没有不一致），以及每个记录目录与索引（没有遗漏）。
