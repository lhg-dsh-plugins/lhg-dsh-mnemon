# v0.5.28：Git 同步体验与可靠性

**简体中文** | [English](../../en/releases/v0.5.28.md)

本补丁版本发布 [#365](https://github.com/omdsh-dev/dsh-mnemon/pull/365)、[#366](https://github.com/omdsh-dev/dsh-mnemon/pull/366) 与 [#363](https://github.com/omdsh-dev/dsh-mnemon/pull/363)。

- **Git 同步**（#365）。设置按使用顺序组织：连接仓库、同步、比较远端变化，再调整高级选项。**立即同步**会合并并推送；**检查远端**不写入数据，可选择**仅合并到本机**或**立即同步**。仓库错误会说明是否需要处理凭据、连接或其他问题。备份历史使用独立对话框，自动同步使用 DSH 选择器，每台电脑可以自定义名称。**断开连接**保留本机与远端记忆，并关闭自动同步。Git 同步仍默认关闭。
- **Git 同步可靠性**（#365）。切换仓库或重建已删除的远端分支时会建立新的镜像历史，避免发布上一仓库的提交。并发推送会重新合并后重试一次；重复合并不会反复复制同一份有分歧的档案或空间。可恢复遗留的锁，Git 2.20–2.27 可初始化镜像；改用另一主机的仓库时，原主机的令牌会被清除，除非同时提供新的凭据。状态探测设有 20 秒超时。
- **Desktop 窗口拖动**（#366）。macOS 上记忆系统顶部留白与标题行使用 DSH 的窗口拖动契约，按钮、标签页与对话框保留原有交互。
- **RetainDB 回退**（#363）。写入、删除与列表操作只在当前接口返回 HTTP 404 时使用旧接口。超时、鉴权失败与服务端错误会直接报告，避免再次请求可能造成的重复写入或删除。

## 升级与兼容性

从 v0.5.22 可使用**记忆系统 → 状态 → 检查版本 → 更新**，完成后重启 DSH。安装精确版本：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.28
```

安装后重启正在运行的 DSH。新安装可在插件页选择**立即启用**。明确版本可避免 pnpm 发布后 24 小时的等待窗口选中较早版本。较早的桌面安装升级方式见[兼容性与升级](../reference/compatibility.md)。

如果 Profile 独立维护 RetainDB，也请更新该副本至 `dsh-mnemon-provider-retaindb@0.5.6`，或移除副本并使用 Starter 自带的组件。Starter 会自动锁定新版本。

无需迁移已有记忆。支持的宿主为 **DSH 0.2.0-rc.2**；Git 同步检查也在 **DSH 0.2.1-alpha.2** 上通过。完整 Profile 使用 Node `^22.19.0 || >=24.0.0`。插件 peer 下限及锁定的外部依赖版本不变。
