# Product media / 产品素材

The current product gallery is [v0.5.32 in Light appearance](./webui-v0.5.32/README.md): 56 bilingual screenshots and ten recordings of a seeded, fictional project, captured from a real DSH 0.2.1 WebUI with the live DeepSeek model answering and a local embedding service. Use it for the README, guides and configuration illustrations. Regenerate it with `node scripts/serve-e2e.mjs --docs-demo --live-model` (or `--docs-demo=en --live-model`) and the steps in its record. The [v0.5.19 gallery](./webui-v0.5.19/README.md), captured on DSH 0.1.7-rc.2, stays as a dated record. Skills has its own [v0.5.34 Skills gallery](./skills-v0.5.34/README.md): 22 bilingual screenshots of the same project, from a pass with the scripted docs demo model.
